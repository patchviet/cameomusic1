Cách cài Việt hóa

  1. Tải bản Việt hóa từ trang chi tiết game.
  2. Giải nén file bằng 7-Zip hoặc WinRAR.
  3. Copy toàn bộ file trong thư mục giải nén đè vào thư mục cài đặt game (thường chứa file .exe).
  4. Chạy game bình thường. Nếu có file .exe riêng của patch thì chạy file đó trước.

Fix Font (chữ bị lỗi / ô vuông)

  • Cài font Việt hóa đi kèm trong bản patch (thường là file .ttf / .otf).
  • Đảm bảo Windows đang dùng UTF-8 (Settings → Time & Language → Language → Administrative language settings).
  • Dùng tool Fix Font trong tab Tool nếu vẫn lỗi.

Fix Save (mất save / không load được)

  • Backup thư mục save trước khi cài patch.
  • Một số game cần xóa save cũ hoặc dùng tool Auto Backup Save.
  • Kiểm tra quyền ghi thư mục Documents / AppData.

Fix Crash / Lỗi thường gặp

  • Chạy game / patch với quyền Administrator.
  • Tắt antivirus tạm thời khi cài (một số patch bị false-positive).
  • Cài Visual C++ Redistributable, DirectX mới nhất.
  • Dùng tool Fix Crash trong tab Tool.
